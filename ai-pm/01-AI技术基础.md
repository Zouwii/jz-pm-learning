## Q3: AI 大模型和传统工程化的边界在哪里？怎么判断该不该用 AI？

> **一句话**：先用工程方法解决 80% 的确定性问题，再用 AI 解决 20% 的模糊问题。反过来——先上 AI 再补工程——会导致不可控的质量问题。

### 核心判断框架

| 维度 | 适合工程化 | 适合 AI |
|------|-----------|---------|
| **输入是否确定** | 确定的（if-else 能穷举） | 开放式的（自然语言、图像） |
| **规则是否明确** | 明确的（业务规则、计算公式） | 模糊的（需要理解语义） |
| **是否需要创造性** | 不需要（标准化流程） | 需要（内容生成、推理） |
| **容错要求** | 零容错（金融交易） | 可容错（搜索、推荐） |
| **数据特征** | 结构化、标签化 | 非结构化、多模态 |
| **更新频率** | 低频（业务规则稳定） | 高频（知识持续变化） |

### 具体场景判断

| 场景 | 用 AI？ | 理由 |
|------|---------|------|
| 计算员工工时 | ❌ 工程化 | 规则明确、零容错 |
| 理解文档内容回答问题 | ✅ AI | 非结构化、开放式查询 |
| 审批流程流转 | ❌ 工程化 | 规则确定，不需要"理解" |
| 自动生成周报摘要 | ✅ AI | 需要理解+生成，容错较高 |
| 数据库 CRUD | ❌ 工程化 | 确定性高，AI 反而可能出错 |
| 语义搜索 | ✅ AI | 同义词、口语化，规则穷举不了 |
| 图像质检（合格/不合格） | ⚠️ 看情况 | 规则明确→传统 CV；模糊标准→AI |

> 具体工程/AI 边界划分案例见 [02-RAG系统设计 Q7](./02-RAG系统设计.md)

### 实用判断公式

```
适合用 AI = 
  输入不确定（自然语言/图像/音频）
  × 输出不需要 100% 精确
  × 人工做成本高/速度慢
  × 有足够的测试数据验证效果

四个全满足 → 用 AI
一个不满足 → 慎重
两个不满足 → 大概率不该用
```

**面试金句**：
> "先用工程方法解决 80% 的确定性问题，再用 AI 解决剩余 20% 的模糊问题。反过来——先上 AI 再补工程——往往会导致不可控的质量问题。"

## Q6: AI 行业有哪些关键发展节点？

> **一句话**：从 2017 年 Transformer 架构奠定基础，到 2022 年 ChatGPT 引爆，再到 2025-2026 年 Agent 从实验走向生产——AI 行业经历了"架构突破 → 规模验证 → 产品爆发 → Agent 落地"四个阶段。

### 大模型关键时间线

| 时间 | 事件 | 意义 |
|------|------|------|
| 2017.06 | Google 发布 Transformer 论文 | 奠定现代 LLM 架构基础 |
| 2020.05 | OpenAI 发布 GPT-3 (175B) | 展示大模型 emergent ability |
| 2021.06 | GitHub Copilot 发布（基于 Codex） | AI 编码助手进入主流 |
| 2022.11 | **ChatGPT 发布** | 🔥 引爆全球 AI 浪潮 |
| 2023.03 | GPT-4 + Claude 发布 | 多模态、推理、安全对齐 |
| 2023.06 | Agent 概念爆发（AutoGPT, BabyAGI） | Agent 范式进入公众视野 |
| 2024-2025 | DeepSeek-V3、Qwen、GLM 等国产模型崛起 | 中文能力 + 成本优势 |
| 2025-2026 | MCP 协议、AI IDE（Cursor/Windsurf）成熟 | Agent 从实验走向生产 |

### Agent 概念演进

Agent 不是新概念——1980 年代就在研究。关键是 **2023 年是 LLM-based Agent 的爆发点**：

- 2023.03：AutoGPT 发布，展示 LLM 自主分解目标执行多步任务
- 2023.04：BabyAGI、AgentGPT 涌现
- 2023.06：LangChain Agent 模块成熟
- 2024-2025：Agent 从玩具走向生产（客服 Agent、编码 Agent、数据分析 Agent）

> Agent 的详细讨论见 [03-Agent与平台工具](./03-Agent与平台工具.md)

### Claude 和 Codex 的关键时间点

- **Codex**：2021.08 发布，2021.10 GitHub Copilot 上线——AI 编码助手的开端
- **Claude**：2023.03 发布，2023.07 Claude 2 支持 100K 上下文
- **Claude Code**：2025 年推出，Agent 能力直接嵌入开发环境

### 已验证的落地场景

| 场景 | 案例 | 成熟度 |
|------|------|--------|
| 编码助手 | GitHub Copilot, Cursor | ⭐⭐⭐⭐⭐ |
| 客服机器人 | 电商/金融客服 | ⭐⭐⭐⭐ |
| 知识库问答 | 企业 RAG | ⭐⭐⭐⭐ |
| 文档生成 | 合同/报告自动生成 | ⭐⭐⭐ |
| 数据分析 | 自然语言查数据库 | ⭐⭐⭐ |
| Agent 自动化 | 流程自动化 | ⭐⭐ |
