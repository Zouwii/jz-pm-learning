## Q17: AI PM 有哪些细分方向？各有什么特点？

> **一句话**：五大方向——AI Native（做 AI 产品本身）、AI 平台（让别人能搭 AI）、AI 赋能（让已有产品变智能）、AI 解决方案（帮行业用 AI）、AI Agent 平台（帮企业搭 Agent）。你的最佳卡位是 AI 解决方案（机器人/智能制造方向）。

### 五大方向全景

| 方向 | 做什么 | 代表公司 | 核心能力 |
|------|--------|---------|---------|
| **AI Native** | AI 就是产品本身 | ChatGPT, Kimi, Midjourney | 模型体验设计、prompt 交互 |
| **AI 平台** | 让开发者搭 AI 应用 | Dify, LangChain, 百炼 | 开发者体验、API 产品化 |
| **AI 赋能** | 已有产品 + AI 能力 | 钉钉AI, Notion AI, Copilot | 场景挖掘、工作流嵌入 |
| **AI 解决方案** | 行业 AI 方案落地 | 第四范式, 行业 ISV | 行业 Know-how + AI 落地 |
| **AI Agent 平台** | 企业 Agent 搭建平台 | Coze, 天宽, 澜码 | Agent 编排 + 客户方案 |

### 五大方向核心对比

| 维度 | AI Native | AI 平台 | AI 赋能 | AI 解决方案 | AI Agent 平台 |
|------|-----------|---------|---------|------------|--------------|
| 热度 | 🔥🔥🔥🔥 | 🔥🔥🔥🔥🔥 | 🔥🔥🔥 | 🔥🔥🔥 | 🔥🔥🔥🔥🔥 |
| 竞争 | 极激烈 | 激烈 | 中等 | 较低 | 激烈 |
| 你的匹配度 | ★★ | ★★★ | ★★★★ | ★★★★★ | ★★★ |

### 你的定位

```
我是一个以 AI 赋能为核心、面向 B 端企业场景、
具备机器人/智能制造行业知识的 AI 产品经理。

差异化优势：
  ✅ 机器人行业知识（导航/伺服/AGV 调度）
  ✅ AI 落地实战（RAG + Agent + MCP + 评测体系）
  ✅ 工程能力（能搭架构、能写代码）
  = 纯 AI 背景和纯行业背景的 PM 都不具备的组合
```

### 职业发展三条路径

```
当前 → AI 赋能型 PM

  ├─ 路径 1：深耕 AI 赋能 → 去大厂 SaaS（钉钉AI/飞书/Notion AI）
  ├─ 路径 2：转向 AI 解决方案 → 机器人行业 AI 方案公司
  └─ 路径 3：转向 AI 平台 → Dify/向量数据库/MCP 生态公司
```

**面试回答模板**：
> 我目前是 AI 赋能型 PM 为主，兼具解决方案型特征。我的核心竞争力不是追风口，而是在一个几乎没人做的交叉点建立不可替代性——机器人行业知识 × AI 落地实战经验。大多数 AI PM 要么懂 AI 不懂行业，要么懂行业不懂 AI，两者的交叉点恰好是解决方案型 AI PM 最需要的能力。

## Q18: AI 解决方案 PM 的前景怎么样？

> **一句话**：AI 解决方案正处 2-3 年的黄金窗口期。但长期看，只会做定制的会被大厂免费 AI 压垮。真正的价值在于从项目中提炼可复用的产品——从服务升级到产品。

### 市场判断

```
2025-2027：黄金窗口
  ├── 企业有 AI 焦虑，愿意花钱试
  ├── 大模型能力快速提升，能解决的场景越来越多
  └── 自建 AI 团队成本高 → 外包给方案商

2027-2029：分化
  ├── 头部方案商 → 产品化，做成行业 SaaS
  ├── 腰部方案商 → 被大厂免费 AI 挤压
  └── 尾部方案商 → 退化为纯人力外包

2029+：剩者为王
  └── 活下来的都有不可替代的行业数据壁垒
```

### AI 解决方案 vs 传统 SaaS

| 维度 | AI 解决方案 | 传统 SaaS |
|------|-----------|-----------|
| 交付 | 项目制，定制化高 | 产品制，标准化高 |
| 收入 | 一次性项目费 + 运维 | 订阅制，持续收入 |
| 规模化 | 难，每个客户要适配 | 易，一套多客户复用 |
| 毛利率 | 30-50% | 70-90% |
| 护城河 | 客户关系 + 行业知识 | 产品体验 + 网络效应 |

### 进化路径

```
第一阶段：纯项目制（定制，赚辛苦钱）
     ↓
第二阶段：半产品化（80% 标准 + 20% 定制）
     ↓
第三阶段：行业 SaaS（开箱即用）
     ↓
终局：行业 AI 平台（客户自配置，方案商提供底座）
```

> 判断一家 AI 方案公司是否值得去的标准：看它处在第几阶段。永远是第一阶段 = 高级外包。

### 四类 PM 横向对比（补充机器人/AGV视角）

| 维度 | AI PM (Native) | AI 解决方案 | 机器人 PM | AGV 方案 |
|------|---------------|------------|----------|---------|
| AI 依赖度 | 极高 | 高 | 低 | 极低 |
| 毛利率 | 70-90% | 30-50% | 40-60% | 20-40% |
| 天花板 | 极高 | 中高 | 中高 | 中 |
| 稳定性 | 中 | 中高 | 高 | 高 |
| AI 冲击 | 低（风口） | 中（大厂挤压） | 低（硬件壁垒） | 极低 |

**面试回答模板**：
> AI 解决方案正处 2-3 年的黄金窗口——企业有 AI 焦虑但自建成本高。但长期看，只会定制交付的会被大厂免费 AI 碾压。真正的价值在于从项目经验中抽象产品。AI 解决方案的终局不是做更多项目，而是从项目中提炼可复用的产品。

## Q19: AI Agent 平台型 PM 是什么方向？

> **一句话**：做让别人能搭 AI Agent 的平台——既像 AI 平台（做工具），又像解决方案（为大客户定制）。当前最热赛道之一，但面临大厂碾压和高定制化陷阱。

### 这方向做什么

```
AI Agent 平台 PM 日常工作：
  ├── 定义 Agent 平台的 tool/plugin 体系
  ├── 设计 Agent 编排和工作流引擎
  ├── 对接大客户，挖掘 Agent 落地场景
  └── 管理 Agent 效果评估和迭代
```

### 跟你的方向对比

| 维度 | Agent 平台 PM | 你（AI 赋能/解决方案） |
|------|-------------|---------------------|
| 当前热度 | 🔥🔥🔥🔥🔥 最热赛道 | 🔥🔥🔥 稳定增长 |
| 薪资天花板 | 较高 | 中高 |
| 竞争 | 极高（大厂+创业公司） | 中（交叉领域竞争少） |
| 被替代风险 | 中等（大厂碾压） | 较低（行业壁垒） |
| 可迁移性 | 高（平台经验通用） | 中（行业绑定） |
| 创业可能 | 高 | 中 |

### 你已有的可迁移经验

```
✅ RAG 知识库  → Agent 核心 Tool
✅ MCP Server   → Agent 与外部系统交互标准
✅ Skills 设计  → Agent 行为编排
✅ 评测体系    → Agent 效果评估
❌ 平台思维    → 需补充（API 设计、开发者体验）
❌ 生态建设    → 需补充（Plugin 市场、社区）
```

### 杭州相关公司

| 公司 | 特点 |
|------|------|
| **Dify** | 开源 Agent 框架，全球影响力 |
| **实在智能** | RPA + AI Agent，已 C 轮 |
| **阿里云百炼** | 大厂 Agent 平台 |

**面试回答模板**：
> AI Agent 平台是当前最热赛道之一，但面临核心矛盾——平台想做标准化产品，大客户需要深度定制，很容易滑向高级外包。真正能活的平台要么有不可替代的技术壁垒（如 Dify 的开源生态），要么有不可替代的客户关系，要么有不可替代的行业数据。我自己更偏 AI 赋能/解决方案方向，因为行业壁垒比平台壁垒更难复制。

## Q20: AI PM 这个岗位的前景怎么样？

> **一句话**：AI PM 会从"特殊岗位"变成"基础能力"——就像现在 PM 都需要懂数据分析。真正稀缺的是能定义 AI 产品评估标准、能设计 Agent 工作流、能做模型选型 trade-off 的 PM。

### 核心能力变化

| 传统 PM | AI PM |
|---------|-------|
| 写 PRD | 写 Prompt 和评估标准 |
| 画原型 | 定义 Agent 行为流程 |
| 用户调研 | 构建评测数据集 |
| 竞品分析 | 模型选型评估 |
| 数据分析 | 精度/召回/延迟分析 |

### 3-5 年趋势

- AI PM 会从"特殊岗位"变成"基础能力"
- 真正稀缺：能定义评估标准、设计 Agent 工作流、做模型 trade-off 的 PM
- 最危险："只会调 API 的 AI PM"——门槛太低，无壁垒

### AI + 机器人 PM：未来交汇点

```
当前（2026）：
  AI PM ────────────────── 机器人 PM
    │                          │
    │  几乎无交集                │

3 年后（2029）：
  AI PM ──────┬────── 机器人 PM
              │
         AI + 机器人交汇：
         • 视觉导航 AI 化
         • 调度 AI 优化
         • 预测性维护 AI 诊断
         • 数字孪生 + AI 仿真

  这个交叉点上的人才极度稀缺。
```

### 你的最佳策略

```
现阶段：主攻 AI 解决方案 PM（机器人/智能制造方向）
        备选 AI 赋能型 PM（企业 SaaS）
        关注 AI Agent 平台方向

核心竞争力不是追风口，而是在交叉点建立不可替代性：
  机器人行业知识 × AI 落地实战经验
  = 未来 3-5 年最稀缺的 AI PM 画像之一
```

**面试金句**：
> "AI PM 的核心竞争力不是'会用 AI'，而是'知道 AI 的边界在哪'——什么时候该用，什么时候不该用，用了能提升多少，风险是什么。"
> "AI Native PM 做的是让 AI 本身成为商品，AI 解决方案 PM 做的是让 AI 帮客户解决实际问题。前者赚技术红利，后者赚行业 Know-how 的钱。技术红利会过期，行业 Know-how 只会越来越值钱。"
