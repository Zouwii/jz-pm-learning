## 三、快速决策：你应该优先看哪些？

### 🔥 第一梯队（高度匹配，优先投）

```
机器人/AI 交叉方向（你最稀缺的能力对应）：
  杭州：海康机器人、宇树科技、蓝芯科技
  上海：快仓智能、仙工智能、梅卡曼德
  深圳：极智嘉、海柔创新、优必选

理由：这些公司需要"懂机器人又懂 AI"的 PM，
      你的背景完美匹配，竞争壁垒高。
```

### 💡 第二梯队（AI 赋能企业 SaaS）

```
有 AI 落地需求的大平台：
  杭州：钉钉、飞书、有赞
  上海：飞书、微盟、销售易
  深圳：腾讯企业微信、金蝶

理由：你的 RAG 落地经验可以直接移植，
      方向更稳，天花板更高，但竞争也更激烈。
```

### 🏢 第三梯队（大厂 AI 平台/云）

```
平台型 AI 岗位：
  杭州：阿里云
  上海：AWS、微软
  深圳：华为云、腾讯云

理由：品牌背书强，但更多是平台思维，
      离你现在的"落地实战"风格有距离。
```

## 四、求职策略建议

### 话术模板（针对机器人/AI 方向）

```
"我目前在机器人行业做 AI 产品落地，核心是把 RAG 知识库问答、
Agent 工作流等能力嵌入企业管理系统中。我有从 0 到 1 搭建
AI 评测体系的实战经验——不是纸上谈兵，是真的构建了标注测试集、
跑了 5 组对照试验的。

我认为 AI 在机器人行业的落地远不止这些——视觉导航的 AI 化、
智能调度、预测性维护、现场问题 AI 诊断，每个方向都需要
既懂机器人业务又懂 AI 能力的 PM。我的背景恰好在这个交叉点上。"
```

### 投递策略

1. **先机器人后 SaaS**：用行业优势争取高匹配度岗位，拿到 offer 后再考虑 SaaS 方向
2. **用项目说话**：把 RAG 对照试验做成 portfolio，面试时直接展示
3. **关注融资新闻**：B轮/C轮的机器人 AI 公司在快速扩张，PM 需求旺盛
4. **猎头渠道**：机器人/AI 交叉方向的猎头资源很集中，让他们帮你匹配
