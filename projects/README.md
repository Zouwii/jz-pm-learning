# Projects：项目事实与讲述

## 目录定位

这里保存三个真实项目的项目事实、个人贡献、证据索引、当前状态和 interview 讲述。

它回答的是：

- 这个项目解决了什么问题；
- 我在其中负责什么；
- 我做了哪些关键决策和行动；
- 有哪些可验证结果与事实边界；
- interview 中如何用 30 秒、2 分钟或 5 分钟讲清楚。

## 三个项目

| 项目 | 主要证明 | 入口 |
| --- | --- | --- |
| Nav-Application | 工业现场、复杂系统、跨模块闭环 | [项目说明](./nav-application/README.md) |
| Management-System | AI 产品、RAG 和评测闭环 | [项目说明](./management-system/README.md) |
| Diagnosis-Agent | Agent、证据闭环和安全边界 | [项目说明](./diagnosis-agent/README.md) |

## 与 `jz-product/` 的边界

公司 PRD 和架构只在 `jz-product/` 保存。项目目录通过链接引用，不复制正文。

`projects/` 可以保存：

- 个人工作证据；
- 项目复盘；
- 决策与事实边界；
- 讲述版本；
- 指向源代码、实验和 PRD 的证据入口。
