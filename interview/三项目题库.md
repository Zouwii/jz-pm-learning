# 三项目 interview 题库

## 使用规则

- 每题先给一句结论，再讲背景、行动、结果和反思。
- 任何技术名词都要回答“为什么在这个项目里需要它”。
- 个人主责与团队实现分开讲。
- 已完成、设计完成、开发中、待验证四种状态不得混用。

## 一、三项目总览

1. 为什么选择这三个项目，它们共同证明什么？
2. 三个项目中哪个最能证明 AI PM 能力？为什么？
3. 从 Nav-Application 到 Diagnosis-Agent，你的能力是怎么递进的？
4. 你在三个项目中分别承担什么角色？
5. 如果只能保留一个项目，你保留哪个？
6. 哪个项目真正有用户，哪个仍属于验证阶段？
7. 三个项目最大的共同问题是什么？
8. 这些项目为什么能支撑你从开发转 AI PM？

## 二、Nav-Application

1. 到点精度自学习解决的到底是什么业务问题？
2. 为什么静态补偿不够？
3. 补偿数据为什么要包含楼层、载荷和定位方式？
4. 采集、计算、分发、应用的完整时序是什么？
5. 如何避免补偿被错误场景复用？
6. 二维码与激光定位源切换为什么是状态机问题？
7. 单边、旋转边和末边分别有什么风险？
8. 你个人负责什么，团队框架负责什么？
9. 最严重的一个 Bad Case 是什么，你如何定位？
10. 用什么指标证明项目有效？当前还缺哪些数据？
11. 如果以 PM 身份重新做一次，你会先改什么？
12. 这段机器人经历对做 AI 产品有什么价值？

1. 用户是谁，最初痛点是什么？
2. 为什么不用钉钉原生 AI？

5. 为什么不能直接对 55G 数据全量入库？
6. 为什么选择 RAG，而不是 Fine-tuning 或纯工程搜索？
7. 为什么要用 Markdown AST，而不是正则或固定字符切片？
8. 标题、列表、代码、表格和图片分别如何解析？
9. 表格为什么必须重复表头并按行组切分？
10. OCR 和视觉摘要分别解决什么问题？
11. 图片 artifact 如何关联原文、检索结果和原图？
12. 为什么采用父子 chunk，而不是所有块一个大小？
13. 为什么同时做 BM25、向量检索和标题路径召回？
14. RRF 如何融合多路结果？
15. 为什么还需要 reranker？
16. checksum、parser version 和 chunker version 如何保证幂等重建？
17. 100—200 文档 canary 如何抽样才有代表性？
18. 新 40 题评测集为什么这样分类型？
19. 图片问题除了 Recall 还要评什么？
20. ACL 如何在所有召回通道一致生效？
21. 旧 26 题测试集为什么不能直接证明 RAG v2？
22. legacy Recall@5 34.13%→59.60% 能说明什么，不能说明什么？
23. 如何从 legacy 表迁移到 v2，又不影响当前服务？
24. 离线评测和用户满意度之间还差什么？
25. RAG、Skills 和 MCP 在产品里分别承担什么角色？
26. 这次重构最重要的产品决策是什么？
27. 这个项目最大的失败或遗憾是什么？

## 四、Diagnosis-Agent

1. 为什么这是 Agent，而不是脚本或 chatbot？
2. 为什么 Agent 不能直接分析所有原始日志？
3. Agent、Engine、Playbook 的边界怎么定？
4. 为什么一次 Case 只能选择一个采集入口？
5. LangGraph 中有哪些关键节点和条件分叉？
6. 错误码路径与多 Agent 路径有什么区别？
7. doc agent 和 field agent 结论冲突怎么办？
8. confirmed、likely、need_human、insufficient_data 如何判定？
9. 如何控制幻觉、误诊和误操作？
10. 哪些动作必须 Human-in-the-Loop？
11. 如何处理模型/API/SSH/知识库不可用？
12. 如何评估入口识别、路由、证据和报告质量？
13. 当前哪些已经完成，哪些仍是 mock 或设计？
14. V1 为什么不直接做自动修复？
15. 如何把一次诊断沉淀成下一次可用的知识？
16. 如果只给三名工程师和三个月，你怎么排优先级？

## 五、场景压力题

1. 用户说 RAG 还是不好用，你先看什么？
2. Recall 上升但用户满意度下降，可能是什么原因？
3. Diagnosis-Agent 给出错误结论并影响现场，责任边界怎么设计？
4. 知识库内容互相冲突，系统应该相信谁？
5. 模型费用突然增加五倍，三个项目分别怎么降本？
6. 要把 Diagnosis-Agent 卖给另一家 AGV company，最大的产品化障碍是什么？
7. 让你用四周把三个项目包装成一个对外方案，你怎么取舍？
8. 哪个项目最能体现你的产品判断，而不仅是开发能力？
