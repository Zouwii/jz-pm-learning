## 三、严格范围

### Diagnosis-Agent V1 只做

- 优先跑通“本地日志 Case”入口，确保可重复回放；
- `create Case → collect → deterministic scan → Playbook/历史证据 → fusion → report → SSE`；
- 结论状态：`confirmed / likely / need_human / insufficient_data`；
- 3 个真实 Case 的人工评测；
- 一个成功 Case、一个失败/降级 Case 的 Demo。

### Diagnosis-Agent 暂不做

- 四个入口同时完整上线；
- 多租户和完整权限后台；
- 全量多 Agent 仲裁；
- 自动修复和外部写入；
- 52 个 Playbook 全部完善。

### RAG v2 第一阶段只做

- 55G 数据统计、抽样和类型分层；
- Markdown AST、HTML 清洗、标题/列表/表格/image block；
- 图片 asset 管理、OCR artifact、原图回链；
- 父子 chunk、BM25 + dense + RRF + reranker；
- checksum 幂等重建；
- 代表性 canary 数据集和新评测集；
- 旧链路与 v2 的可复现实验。

### RAG v2 暂不做

- 未经抽样验证直接全量处理 55G；
- 对 19,886 张图片全部调用视觉大模型；
- Graph RAG、复杂 HyDE、多 Agent RAG；
- 删除旧表或直接切换全部线上流量；
- 用旧 26 题结果证明新系统效果。
