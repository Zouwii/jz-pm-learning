# PM Learning

这个仓库只做三件事：学习 PM、整理公司产品材料、沉淀项目讲述。

## 从哪里开始

日常学习只打开：[00-开始学习](./00-开始学习.md)。

```text
00-开始学习.md
       ↓
interview：回答和训练方法
       ↓
projects：需要讲项目时再看
       ↓
jz-product：需要查原始 PRD 和设计细节时再看
```

## 目录边界

### `interview/`：我怎么回答

只保存实际训练过的 QA 和回答方法：

- [AI PM QA](./interview/AI-PM-QA.md)
- [普通 PM QA](./interview/普通-PM-QA.md)
- [结构化思考训练](./interview/结构化思考训练.md)
- [Agent 与 Workflow 思考训练](./interview/思考训练-Agent与Workflow.md)

不再存放工程冲刺表、项目状态或尚未训练的题库。

### `jz-product/`：公司已有产品材料

保存公司已有 PRD、架构设计，以及需要继续分析和完善的产品材料。这一层是产品事实源，不负责 interview 包装。

### `projects/`：我做过什么

保存三个项目的事实、个人贡献、证据、当前状态和讲述方式。项目文档可以引用 `jz-product/`，但不复制公司 PRD 正文。

## 三条规则

1. 同一份 PRD 只在 `jz-product/` 保留一份；
2. `projects/` 只写项目事实、贡献、证据和讲述；
3. QA 只有实际回答并点评后才进入 `interview/`。
