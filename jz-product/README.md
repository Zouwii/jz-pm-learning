# JZ Product：公司产品材料

## 目录定位

这里保存公司已有的 PRD、架构设计，以及需要继续分析和完善的产品材料。

这层回答的是：

- 公司原本怎么定义产品；
- PRD 和架构提出了什么目标、范围与约束；
- 哪些需求、指标、风险和验收标准仍需补充；
- 后续应如何完善产品设计。

它是产品事实源，不负责包装个人贡献或 interview 话术。

## 与 `projects/` 的边界

| `jz-product/` | `projects/` |
| --- | --- |
| 公司 PRD 与架构原件 | 项目的一句话、背景与当前状态 |
| 产品目标、范围和设计 | 我的职责、行动和证据 |
| 待完善的需求与指标 | 30 秒、2 分钟和追问口径 |
| 作为事实源持续修订 | 只引用，不复制 PRD 正文 |

需要完善 PRD 时修改本目录；需要准备项目回答时修改 `projects/`。
