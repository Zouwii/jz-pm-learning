# PRD 阅读学习 ①：全向车 CE 方案

> 这是 PRD 阅读学习系列的第一篇。我们不逐字翻译文档，而是学习**怎么拆解一份 PRD**——找出它到底在解决什么问题。

---

## 一、PRD 阅读方法论

拿到一份 PRD，先问三个问题：

| 问题 | 目的 |
|------|------|
| **这份 PRD 写给谁看？** | 确定信息密度和术语层级 |
| **它在解决什么核心矛盾？** | 找出一句话能说清的本质 |
| **关键约束是什么？** | 技术方案的天花板在哪 |

以「全向车 CE 方案 PRD」为例：

1. **写给谁看**：嵌入式工程师、安全工程师、项目经理（不是给客户看的）
2. **核心矛盾**：全向车有直行和横移两种运动模式，安全激光的保护区域必须跟着运动方向切换，而切换依据（舵轮角度）有严格的物理约束
3. **关键约束**：CE 认证要求，硬件上舵轮安全接近开关只能检测 0° 和 ±90°，且容差仅 ±5°

## 二、术语速查表

阅读 PRD 的第一个障碍永远是术语。先建字典：

| 术语 | 全称 | 一句话解释 |
|------|------|-----------|
| **CE** | Conformité Européenne | 欧盟安全认证，比国标严格 |
| **PLC** | Programmable Logic Controller | 硬件级别的控制器，负责"硬安全" |
| **硬安全** | Hard Safe | PLC 控制的急停，直接断电，人绝对不能受伤 |
| **软安全** | Soft Safe | 导航软件控制的平滑减速，日常避障用 |
| **Muting** | — | 临时关闭/缩小激光保护区域，限速 0.3m/s |
| **Stop 0** | — | 电机瞬间断电停车，最暴力的停车方式 |
| **轮廓外区域** | — | 车体外扩出去的安全检测矩形 |
| **iobox** | — | 安全IO盒子，PLC 和导航之间的中间件 |
| **Carly** | — | 车载控制器，决策层 |
| **舵轮** | Steering Wheel Unit | 全向车的驱动轮单元，可独立控制角度和速度 |
| **安全接近开关** | Safety Proximity Switch | 检测舵轮是否转到 0° 或 ±90° 的硬件传感器 |

## 三、全向车 CE 方案核心问题拆解

### 3.1 为什么差速车没这么复杂？

```
差速车（EMMA）：
  两轮差速 → 只能前进/后退/原地旋转
  → 运动方向永远 = 车头方向
  → 安全激光永远保护车头前方
  → 不需要切换！
```

```
全向车（OMNI）：
  双差分舵轮 → 前进/后退/横移/原地旋转
  → 直行时激光应保护前方
  → 横移时激光应保护侧面
  → 必须切换！而且切换不能出错！
```

### 3.2 核心矛盾：PLC 怎么知道车在横移还是直行？

PLC 是硬件，它不跑导航算法。它只能通过一个东西判断——**舵轮角度**。

```
舵轮在 90°±5°  → PLC 判定 = 横移 → 激光保护侧面
舵轮在 0°±80°  → PLC 判定 = 直行 → 激光保护前方
```

这个**两档判断**是整个方案的物理天花板。

### 3.3 最大的坑：舵角漂出 ±5°

如果横移过程中舵角偏差超过 ±5°（比如偏到 83°）：

```
时序：
  1. PLC 看到舵角 83° → "哦，在直行" → 激光切到保护前方
  2. 但车实际在横移（侧面在移动）
  3. 侧面撞到货架 → 激光没反应（激光在看前方）
  4. 安全机制失效 → 危险！
```

这就是文档里描述的**死亡循环**：

```
横移 → 舵角超 ±5° → PLC 误判直行 → 激光区域错误
→ 检测到侧面障碍 → 硬安全掉电 → 2-3s 后自恢复
→ 导航继续发横移速度 → 又超 ±5° → 又掉电 → 无限循环
```

**所以横移对舵轮控制精度要求极高。**

## 四、安全保护区域的"翻译"

### 4.1 先建坐标系

文档用四个变量描述车体和负载：

```
L  × W   = 车体长 × 车体宽
Ld × Wd  = 负载长 × 负载宽（搬了货的情况）
a, b     = 激光传感器在车体上的安装偏移量
```

### 4.2 一条记录的读法

```
场景1：空载 X正方向行驶
速度 0.8-1.2m/s
轮廓外区域 [135, 15]
激光1 [L-a+6, b+15] - [a+135, W-b+15]
激光2 [L-a+6, b+15] - [a+6, W-b+15]
```

翻译成人话：

> 车空载向前跑，速度在 0.8~1.2m/s 之间时：
> - 在车体前方画一个 **长 135cm、左右各宽 15cm** 的保护矩形
> - 激光1 负责这个矩形的大部分区域
> - 激光2 负责紧贴车头的窄条（因为激光2 在车的另一边，视角受限）

### 4.3 九个场景 = 九种"框的摆法"

```
方向    │ 空载                │ 载货
────────┼─────────────────────┼─────────────────────
直行前进 │ 场景1：框在车头前     │ 场景5：框在货的前方
直行后退 │ 场景2：框在车尾后     │ 场景6：框在货的后方
横移左   │ 场景3：框在车体左侧   │ 场景7：框在货的左侧
横移右   │ 场景4：框在车体右侧   │ 场景8：框在货的右侧
────────┼─────────────────────┼─────────────────────
待机     │ 场景9：框几乎为0      │
原地旋转 │ 场景9：框四周扩15cm    │
Muting   │ 场景9：框=0，限速     │
```

### 4.4 速度与保护框长度的关系

```
速度      空载保护框长度    逻辑
0~0.3m/s    40cm         低速，刹车距离短
0.3~0.5m/s  60cm
0.5~0.8m/s  85cm
0.8~1.2m/s  135cm        高速，必须提前很远检测
```

> **直觉理解**：这和开车一个道理——车速越快，跟车距离越远。保护框长度 = 刹车距离 + 安全余量。

## 五、PRD 中的其他关键设计决策

### 5.1 运动能力取舍

```
✅ 支持：直行、横移、原地旋转
❌ 不支持：斜向移动、曲线运行、任意角度平动
```

为什么？因为斜向运动时舵轮角度不在 0° 也不在 90°，PLC 无法判断运动方向，激光区域不知道往哪切。**安全第一，能力妥协。**

### 5.2 直行横移切换必须停车

```
直行 → 停车 → 舵轮转 90° → 横移
横移 → 停车 → 舵轮转 0°  → 直行
```

运动中切换会导致舵轮动态角度漂移超出 ±5°，触发安全问题。

### 5.3 Muting 模式：安全的最后防线

```
正常模式：激光保护区域全开，有障碍就停车
Muting：  关闭所有激光保护，强制限速 0.3m/s
```

什么时候用 Muting？

| 场景 | 为什么 |
|------|--------|
| 货架下对接 | 四面都是货架腿，激光开着车动不了 |
| 窄通道 | 通道比车宽不了多少，激光会持续误触发 |
| 伺服对接 | 需要贴得很近，激光保护区域阻碍到位 |

> **代价**：Muting 下全速仅 0.3m/s，对接效率低，但这是 CE 认证的硬要求。

### 5.4 速度限制体系

```
非 Muting 直行：     车型最大速度（1.2m/s 空载）
非 Muting 横移：     车型最大横移速度（0.5m/s）
非 Muting 原地旋转： 轮廓切向 1m/s
Muting（任何运动）： 强制 0.3m/s
手柄遥控：          强制 0.7m/s
```

## 六、这份 PRD 教会我们什么

### 6.1 读 PRD 的核心能力

| 能力 | 在这份 PRD 中的体现 |
|------|-------------------|
| **识别核心矛盾** | 全向运动 vs 安全激光不能跟着转 |
| **理解物理约束** | 舵轮接近开关只能检测两档，容差 ±5° |
| **看懂参数表** | 速度-保护框长度表 = 刹车距离的工程化表达 |
| **理解设计取舍** | 不支持斜移（安全换功能）、Muting 限速（效率换安全） |

### 6.2 PM 视角的关键发问

拿到这类 PRD，PM 应该问：

1. 舵轮 ±5° 容差在量产中能稳定达到吗？如果不能，方案要不要改？
2. Muting 限速 0.3m/s 对整体节拍影响多大？客户能接受吗？
3. 斜移不支持，哪些客户场景会受影响？竞品支持吗？
4. 载货后保护框按负载算——如果客户用非标载具怎么办？

### 6.3 和 EMMA 差速车的对比认知

| 维度 | EMMA 差速车 | OMNI 全向车 |
|------|-----------|------------|
| 运动模式 | 前进/后退/旋转 | + 横移 |
| 激光区域 | 始终朝车头，不切换 | 直行/横移需切换 |
| 安全复杂度 | 低 | 高（舵轮角度联动） |
| 横移节拍优势 | 无 | 窄通道场景显著提升 |
| CE 认证难点 | 标准 | 舵轮角度检测精度 |
